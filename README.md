# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Выполнил: Студент 3-го курса
**Направление:** Прикладная математика и информатика
**Дисциплина:** Введение в интеллектуальную обработку данных

### 1. Описание проекта
В данной работе проведен первичный аудит качества данных на примере личного датасета рынка недвижимости. Цель работы — выявление пропусков, полных дубликатов и аномальных значений (выбросов) в данных.

### 2. Структура проекта
- `01_data_understanding.ipynb` — основной файл лабораторной работы с кодом на Python, расчетами и визуализацией распределений.

### 3. Результаты аудита данных
- **Размерность:** В ходе анализа проверена таблица, содержащая более 500 строк и 8 ключевых признаков.
- **Пропуски:** Обнаружены и зафиксированы пропущенные значения (Missing Values) в столбцах стоимости жилья (`price`) и количества комнат (`rooms`).
- **Дубликаты:** Успешно локализованы и подсчитаны полностью повторяющиеся строки.
- **Выбросы:** С помощью метода межквартильного размаха (IQR) исследованы экстремальные значения стоимости объектов.

### 4. Инструкция по запуску
Проект выполнен в среде Google Colab (Jupyter Notebook). Все ячейки с кодом воспроизводимы и запускаются последовательно сверху вниз без ошибок.
